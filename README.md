# vibe-on-wheels
Вайб на колёсах - Разработка приложений для мобильных платформ

Для запуска надо скачать flutter + android studio (flutter SDK)

запустить в android studio эмулятор "телефона", после его загрузки перейти в папку с проектом (medium phone с 35 версией api и 15 android (Vanilla Ice Cream)

В папке с проектом выполнить команды flutter pub get потом выполнить команду flutter create . и flutter run и выбрать запушенный девайс

## Структура проекта

```
lib/
  data/
    mock_data.dart              ← все моковые данные
    trip_repository_impl.dart   ← имитация GET
    booking_repository_impl.dart← имитация POST
  domain/
    entities/                   ← модели данных
    repositories/               ← интерфейсы
    use_cases/                  ← бизнес-логика
    enums.dart
  presentation/
    viewmodels/
      auth_view_model.dart      ← авторизация
      trip_view_model.dart      ← поиск и бронирование
    screens/                    ← экраны приложения
    theme/app_theme.dart
  main.dart
```
## Где находятся моки

Все моковые данные собраны в одном файле: `lib/data/mock_data.dart`

| Данные | Описание 
|--------|----------|
| `mockDrivers` | 4 водителя с машинами |
| `mockUsers` | пользователи для входа |  
| `generateMockTrips()` | поездки по маршруту | 
| `createMockBooking()` | создание бронирования | 

Сетевая задержка имитируется через `Future.delayed(800ms)`.

## Реализованный сценарий

**End-to-end: пассажир бронирует поездку**

1. Открыть приложение → экран авторизации
2. Ввести номер телефона: `+7 999 123-45-67` → нажать **Войти**
3. Перейти во вкладку **Поездки**
4. Ввести маршрут на русском, например: `Томск` → `Новосибирск`
5. Нажать **Найти** → увидеть список из 4 поездок
6. Нажать на любую поездку → открываются детали
7. Нажать **Забронировать** → появится уведомление "Поездка забронирована"
8. Через 3 секунды — уведомление "Водитель принял поездку"
9. Открывается экран встречи с картой и данными водителя

**Проверка состояний:**
- `loading` — видно при поиске (спиннер ~800мс)
- `error` — ввести маршрут латиницей (например `Tomsk`)
- `normal` — список найденных поездок
